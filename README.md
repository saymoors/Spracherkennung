# Spracherkennung

Веб-приложение для загрузки аудиофайлов, распознавания речи через SaluteSpeech, просмотра истории транскрипций, анализа статистики текста и экспорта результата в PDF.

## Возможности

- регистрация и вход пользователя;
- авторизация через JWT;
- загрузка аудиофайлов для распознавания;
- выбор языка распознавания;
- поддержка форматов MP3, WAV, FLAC и OGG;
- создание новой транскрипции при каждой попытке распознавания;
- переиспользование готового результата для одинакового файла;
- повторное распознавание уже существующего файла;
- просмотр истории транскрипций;
- просмотр результата, статистики и ошибок обработки;
- экспорт готовой транскрипции в PDF;
- логирование внешних вызовов SaluteSpeech.

Перед запуском должны быть установлены:

- JDK 21;
- Maven;
- PostgreSQL;
- учетные данные SaluteSpeech API.

Для запуска через `spracherkennung.bat` также нужно, чтобы утилита `psql` была доступна из `PATH`. Обычно для этого в `PATH` добавляется папка PostgreSQL `bin`, например:

```text
C:\Program Files\PostgreSQL\18\bin
```

## Настройка окружения

Приложение читает параметры из файла `.env`, расположенного в корне проекта рядом с `pom.xml`.

Пример `.env`:

```env
SERVER_PORT=1807

POSTGRES_HOST=localhost
POSTGRES_PORT=5432
POSTGRES_DB=spracherkennung
POSTGRES_USER=postgres
POSTGRES_PASSWORD=postgres

UPLOAD_DIR=uploads

JAVA_HOME=C:\Program Files\Java\jdk-21.0.10

JWT_SECRET=replace_with_long_secret_key_for_hmac_sha
JWT_EXPIRATION_MS=86400000

SALUTESPEECH_CLIENT_ID=your_client_id
SALUTESPEECH_CLIENT_SECRET=your_client_secret
SALUTESPEECH_AUTH_URL=https://ngw.devices.sberbank.ru:9443/api/v2/oauth
SALUTESPEECH_API_URL=https://smartspeech.sber.ru/rest/v1
SALUTESPEECH_SCOPE=SALUTE_SPEECH_PERS
```

Файл `.env` не должен попадать в публичный репозиторий, так как содержит пароли и ключи доступа.

`JAVA_HOME` нужен только для запуска через `spracherkennung.bat`. Если переменная не задана, bat-файл попробует найти JDK в папке:

```text
C:\Program Files\Java\jdk-*
```

## База данных

При запуске через `spracherkennung.bat` база данных создается автоматически, если она еще не существует. Для этого пользователь PostgreSQL из `.env` должен иметь право `CREATEDB`.

Если приложение запускается без bat-файла, базу данных PostgreSQL нужно создать вручную с именем, указанным в переменной `POSTGRES_DB`.

Например:

```sql
CREATE DATABASE spracherkennung;
```

Таблицы создавать вручную не нужно. При запуске приложение выполняет скрипт:

```text
src/main/resources/schema.sql
```

Скрипт создает таблицы, связи и индексы, если они еще отсутствуют.

## Запуск

### Запуск через bat-файл

Для обычного запуска на Windows можно использовать `spracherkennung.bat`.

В одной папке должны находиться:

```text
spracherkennung.bat
spracherkennung-1.0.0.jar
.env
```

Bat-файл выполняет подготовительные проверки:

- читает параметры из `.env`;
- проверяет наличие `psql`;
- проверяет подключение к PostgreSQL;
- создает базу данных, если она отсутствует;
- находит Java;
- проверяет, что используется Java 21;
- проверяет наличие `spracherkennung-1.0.0.jar`;
- запускает приложение.

Если jar-файл был собран командой `mvn clean package`, его нужно взять из папки `target` и положить рядом с `spracherkennung.bat`.

### Запуск через Maven

Запуск через Maven:

```bash
mvn spring-boot:run
```

### Запуск jar-файла вручную

Запуск собранного jar-файла:

```bash
java -jar target/spracherkennung-1.0.0.jar
```

После запуска приложение доступно по адресу:

```text
http://localhost:1807/
```

Если в `.env` указан другой `SERVER_PORT`, нужно использовать этот порт.

## Основные сценарии

### Первичное распознавание

Пользователь выбирает аудиофайл и язык распознавания. Приложение проверяет файл, сохраняет его на сервере, создает запись аудиофайла и новую транскрипцию со статусом `NEW`. Затем файл отправляется в SaluteSpeech, создается задача распознавания, а транскрипция переходит в статус `RUNNING`.

Планировщик периодически проверяет запущенные задачи. После успешного завершения задача получает статус `DONE`, приложение скачивает результат, сохраняет смысловые блоки текста и статистику.

### Повторная загрузка файла

Если пользователь загружает файл с тем же хэшем, приложение ищет уже существующие данные распознавания.

Если готовая транскрипция уже содержит текст, создается новая транскрипция, в которую копируется готовый результат. Новая задача SaluteSpeech при этом не создается.

Если готового текста нет, приложение использует доступные сохраненные идентификаторы SaluteSpeech, когда они еще действительны, либо запускает новую обработку.

### Повторное распознавание

Кнопка повторного распознавания используется для файла, который уже существует в системе. В этом случае создается новая транскрипция и запускается новая задача SaluteSpeech.

### Ошибки обработки

Если внешний API возвращает ошибку или задача завершается со статусом `ERROR` или `CANCELED`, статус сохраняется в транскрипции. Сообщение последнего внешнего вызова отображается пользователю в окне деталей.

## Примечания по эксплуатации

- Директория загрузок задается переменной `UPLOAD_DIR`.
- Если `UPLOAD_DIR=uploads`, папка создается относительно рабочей директории запуска.
- Если указан абсолютный путь, файлы сохраняются по этому пути.
- Максимальный размер загружаемого файла ограничен настройками multipart в `application.yaml`.
- Для корректного экспорта PDF используется шрифт `RuslanDisplay-Regular.ttf` из ресурсов проекта.
